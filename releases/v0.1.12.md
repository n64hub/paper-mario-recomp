An update of the shared renderer and runtime. Like v0.1.11 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 40 MiB, SHA-1 `3837f44cda784b466c9a2d99df70d77c322b97a0`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `PaperMarioRecompiled-v0.1.12-windows-x64.zip` and run `PaperMarioRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `PaperMarioRecompiled-v0.1.12-linux-x64.tar.gz` and run `PaperMarioRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- The renderer and runtime are updated to N64Recomp-browser v0.200.0's.
- On Linux with Mesa's software Vulkan driver (lavapipe), the game no longer crashes a few seconds in.
- At some window sizes the window's bottom row of pixels stayed black with the Direct3D 12 renderer; it is drawn now.

The [README](https://github.com/n64hub/paper-mario-recomp#readme) has what works and how to build it yourself; reports are welcome on the [issues page](https://github.com/n64hub/paper-mario-recomp/issues).
