The first release of Paper Mario: Recompiled for Windows and Linux: a native PC port of the N64 game made by static recompilation. It is not an emulator and contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 40 MiB, SHA-1 `3837f44cda784b466c9a2d99df70d77c322b97a0`). Other regions and revisions are not supported.

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `PaperMarioRecompiled-v0.1.0-windows-x64.zip` and run `PaperMarioRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `PaperMarioRecompiled-v0.1.0-linux-x64.tar.gz` and run `PaperMarioRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2). Pick your ROM with **Load ROM**, then **Start Game**: the ROM is stored, so the next start goes straight to the game.

**What works:** the intro story, the title and the attract demo with its battles; a new game from file select through the prologue and its first battle; the pause menu; every map of every area, from Goomba Village to Bowser's Castle, Peach's Castle and the minigames; and the ending's parade. Sound (the game's own audio code, recompiled), the game's saves kept across restarts, and keyboard and gamepad input.

**Enhancements**, each an option on the settings menu's Graphics tab with an Original value that plays as the console does:

- High resolution at the window's size, with anti-aliasing
- Smooth motion at the display's refresh rate, blended between the game's frames
- Widescreen: in a window wider than 4:3 the world and the battles reach the window's edges, their backgrounds with them, and the menus and the HUD stay in the middle 4:3
- Keyboard and gamepad controls, rebindable

**Not checked yet:** a whole playthrough from start to end (every map of every chapter has been visited, so expect the odd thing drawn wrong; reports are welcome on the [issues page](https://github.com/n64hub/paper-mario-recomp/issues)), long play sessions, rumble on a pad, and the Linux build on a GPU (it has been booted on Mesa's software Vulkan only, where it runs far too slowly to play).

The [README](https://github.com/n64hub/paper-mario-recomp#readme) has what works and how to build it yourself.
