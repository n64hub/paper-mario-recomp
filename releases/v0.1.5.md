A fix in the shared renderer for parts of one object that flickered at high refresh rates. Like v0.1.4 it contains no game data: you need your own ROM of the USA release (a big-endian `.z64` of 40 MiB, SHA-1 `3837f44cda784b466c9a2d99df70d77c322b97a0`).

> **Made with AI.** Almost all of the code was written by AI agents (Claude), directed and play-tested by a person.

**Windows:** unzip `PaperMarioRecompiled-v0.1.5-windows-x64.zip` and run `PaperMarioRecompiled.exe` from that folder (it needs a recent Visual C++ 2015-2022 redistributable, x64). **Linux (x86-64):** extract `PaperMarioRecompiled-v0.1.5-linux-x64.tar.gz` and run `PaperMarioRecompiled` in that folder (glibc 2.35 or newer, a Vulkan driver, GTK 3 and FreeType; it brings its own SDL2).

**What's new:**

- Parts of one object drawn at one spot and only scaled apart no longer flicker or swap places at high refresh rates.

The [README](https://github.com/n64hub/paper-mario-recomp#readme) has what works and how to build it yourself; reports are welcome on the [issues page](https://github.com/n64hub/paper-mario-recomp/issues).
